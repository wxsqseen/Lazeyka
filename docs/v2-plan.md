# План: Лазейка 2.0

Решение владельца (2026-11-10): v2 — **автопилот** и **карта соединений**. «Лазейку для всего дома» (раздача
телевизору и приставке) владелец исключил.

## Зачем это v2, а не 1.5

В 1.x человек сам выбирает стратегию обхода, пресет маршрутов и списки сайтов. Это работает, но держится на нём: одна
стратегия на всё («чинит YouTube — ломает Discord»), сломалось — нужно идти и подбирать. В 2.0 человек включает один
выключатель, а Лазейка сама собирает обход для каждого сервиса, сама решает, что пустить через свой VPN, а что
напрямую, сама чинит и показывает, что куда идёт и почему. Стратегии и пресеты остаются для опытных, но больше не
нужны для работы.

## Части

### 1. Обход по сервисам и по сайтам (движок)

Все стратегии пакета Flowseal (1.10.3) — одни и те же девять профилей winws с одинаковыми фильтрами и списками;
различаются только параметры обмана DPI. winws применяет первый подходящий профиль. Поэтому «своя стратегия для
сервиса» — честная сборка, а не смесь наугад:

- **YouTube** — профиль `list-google.txt` (TCP 443): его параметры берутся из стратегии, лучшей для YouTube;
- **Discord** — свой профиль `--hostlist-domains=<домены Discord из list-general.txt>` перед общим профилем, с
  параметрами общего профиля стратегии, лучшей для Discord; так же — профиль `discord.media` (TCP 2053…);
- **остальное** — базовая стратегия, как сейчас.

Откуда «лучшая для сервиса»: подбор уже хранит итог каждой стратегии по каждому сайту проверки (`targets.txt`: Discord
×4, YouTube ×4, Google ×2, Cloudflare ×2). После стандартного подбора — лучшая по группам; отличаются — сборка.

Дальше — **свой профиль для отдельного сайта** (рентген: «обход обрабатывает сайт, но не пробивает»): короткий
подбор только для этого сайта (стратегии по очереди, проба рентгена), найденная — профилем сайта перед общим.

Код: `zapret/compose.py` — чистая функция «базовые аргументы + выбор для групп и сайтов → аргументы winws»;
`ZapretManager.build_args` собирает её для работающего обхода (пробы подбора — без сборки); настройка
`zapret.group_strategies` (`{"youtube": id, "discord": id}`), позже `zapret.site_strategies`. Маршрут «через обход»
своего VPN строится по тем же аргументам — новые профили в нём учтутся сами.

### 2. Автопилот (один выключатель)

Главная — один выключатель «Интернет без блокировок»: обход (собранный по сервисам), свой VPN, если есть серверы
(с умным маршрутом), Telegram-прокси. Всё, что в 1.4 было кнопками, работает само: сторож при сбое пересобирает
только сломанную группу (не всю стратегию), спасатель — серверы, умный маршрут — сайты, белый список — честная
плашка вместо перебора. Над выключателем — по строке на сервис: «YouTube — через обход, «ALT2»», «Instagram — через
ваш сервер».

### 3. Карта соединений

Живой список «сайт → каким путём идёт и почему» (своё правило, умный маршрут, обход, пресет) с трафиком и кнопками
«через сервер», «мимо VPN», «подобрать обход». Данные — соединения ядра, которые сэмплер и так берёт раз в 5 с:
видны, когда включён свой VPN (в режиме TUN — все программы). Без своего VPN карта говорит, как её включить.

## Порядок работ

1. Движок: сборка по группам из итогов подбора, настройка, показ на странице «Обход». ✓
2. Подбор для одного сайта и профиль сайта (кнопка рентгена). ✓ Вживую: Instagram — «ALT4» за 12 с, Rutracker и
   Medium — «ALT9» за 10 с; после — открываются, остальной обход на «ALT».
3. Сторож: при сбое одного сервиса — подбор только для него. ✓
4. Карта соединений. ✓
5. Главная с одним выключателем. ✓ Настройки 1.x переносить не нужно: новые ключи с умолчаниями, карточки частей
   остались под выключателем («Подробно — по частям»).

## Проверка

Сборку аргументов проверяют тесты на настоящем пакете (те же разборщики, что строят маршрут своего VPN).

**Вживую, 2026-11-10, сеть владельца** (права администратора, рядом работает Incy; обход — механизмом Лазейки с
фильтром «только прямые подключения, без серверов VPN»; данные — во временной папке; сторож убивал бы winws, перестань
Incy отвечать). Подбор 22 стратегий — 59 с; Discord — 12 проверок, YouTube и Google — 18:

| База | Одна | Со своей стратегией группы (ALT) |
|---|---|---|
| FAKE TLS AUTO | YouTube 18, Discord 0 | YouTube 18, **Discord 12** |
| Стандартная | YouTube 12 (видео ✗), Discord 12 | **YouTube 18 (видео ✓)**, Discord 12 |
| ALT5 | 0 и 0 | 0 и 0 |

ALT5 — один TCP-профиль «все сайты» с syndata: он действует уже на SYN, когда имени сайта не видно, и профили
сервисов перед ним не помогают. Поэтому на такой базе сборка не делается и не советуется (`compose._catch_all`,
`ZapretManager.composable`). У владельца восемь стратегий одинаково хороши и для YouTube, и для Discord — подбор честно
не советует сборку; она нужна там, где лучшие для сервисов расходятся.
