# Лазейка

Одно приложение вместо двух: **zapret** (Discord и YouTube) и **tg-ws-proxy** (Telegram Desktop)
с понятным окном, значком в трее и обновлениями, которые ставятся **только когда вы нажмёте кнопку**.

Внутри — без изменений — работают проекты Flowseal:
[zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) и
[tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy). Лазейка запускает их, настраивает
и обновляет; сами стратегии и прокси — их заслуга.

## Что умеет

**Discord и YouTube (zapret)**
- Включение одной кнопкой; все 22 стратегии пакета, переключение из окна или из трея.
- Подбор стратегии: по очереди пробует стратегии на Discord, YouTube, Google и Cloudflare
  (как `service.bat → Run Tests`) и показывает лучшую. Есть и проверка «DPI 16–20 КБ».
- Игровой фильтр, режимы IPSet (none / loaded / any), обновление списка IP.
- Свои списки сайтов и исключений прямо в окне.
- Работа как служба Windows — обход действует даже без открытой Лазейки.
- Диагностика всех проверок из `service.bat` с кнопками «Исправить», очистка кэша Discord,
  обновление hosts отдельным помеченным блоком с резервной копией.
- При первом запуске находит ваш старый zapret и переносит игровой фильтр, IPSet и свои списки.

**Telegram (tg-ws-proxy)**
- Локальный MTProto-прокси `127.0.0.1:1443`; «Подключить Telegram» открывает ссылку `tg://proxy`.
- Скорость и число соединений в реальном времени, проверка маршрутов до серверов Telegram.
- Все настройки оригинала: DC → IP, Cloudflare-прокси, свои домены, Cloudflare Worker.
- Если стоял TG WS Proxy — переносит его ключ, и ссылка в Telegram остаётся прежней.

**Обновления — по желанию, без принуждения**
- Проверка при запуске включается и выключается в настройках. Найденное обновление —
  это только плашка в окне; браузер сам ничего не открывает.
- «Установить» скачивает обновление в само приложение:
  - стратегии zapret — релизный архив с проверкой SHA-256, опубликованной GitHub;
  - ядро прокси — файлы тега релиза, каждый сверяется с git-хешем этого тега.
- Новая версия ставится рядом с работающей, поэтому «Откатить» возвращает прежнюю за секунду.
  Если новое ядро прокси не запустилось, Лазейка сама возвращает встроенное.
- «Пропустить версию» скрывает напоминание до следующего релиза.

## Где что хранится

| Что | Где |
|---|---|
| Настройки, пакеты стратегий, скачанные обновления, журнал | `C:\ProgramData\Lazeyka` |
| Портативный режим | папка `LazeykaData` рядом с exe — тогда всё хранится в ней |

Папка в ProgramData доступна на запись только администратору: из неё запускается
winws.exe с правами администратора, и папка, куда может писать любая программа,
стала бы дырой для повышения прав.

## Права администратора

winws и драйвер WinDivert без них не работают, поэтому при запуске Лазейка просит права.
Если отказать — откроется ограниченный режим: Telegram-прокси работает, обход и
изменение настроек — нет (кнопка «Перезапустить с правами» вернёт всё).

Автозапуск сделан через Планировщик заданий: так Windows не показывает запрос UAC при входе.

## Безопасность

Лазейка работает с правами администратора, поэтому она устроена так, чтобы этими
правами нельзя было воспользоваться со стороны:

- **Папка данных** доступна на запись только администраторам и SYSTEM. Если её
  создал кто-то другой, содержимое при запуске удаляется и ставится заново.
- **Окно открывает только сам интерфейс.** Переход на любую другую страницу
  (ссылка, перетаскивание в окно) отменяется, веб-ссылки открываются в вашем
  браузере без прав администратора. Дополнительно действует политика CSP.
- **Системные пути** (System32, ProgramData, Program Files) берутся у Windows,
  а не из переменных окружения, которые обычная программа может подменить.
- **Обновления** проверяются: архив zapret — по SHA-256, опубликованному GitHub;
  файлы ядра прокси — по git-хешам тега релиза. Встроенный пакет сверяется
  с хешем, зашитым в код.
- **Автозапуск** запускает копию из `C:\Program Files\Lazeyka` (её делает сама
  Лазейка при включении автозапуска): задание с наивысшими правами не должно
  указывать на файл, который могут подменить, например в «Загрузках».
- Свой VPN, драйвер WinDivert других программ и чужие службы Лазейка не трогает:
  диагностика только сообщает о них, а выгружает лишь драйвер, лежащий рядом
  с `winws.exe` от zapret.

Что остаётся за рамками:
- Один exe при запуске распаковывает библиотеки во временную папку пользователя
  (так работает PyInstaller). Программа, уже запущенная от вашего имени,
  теоретически может вмешаться в этот момент.
- Портативный режим (`LazeykaData` рядом с exe) защищён слабее: папку, лежащую
  в пользовательском каталоге, можно переименовать.
- Если обычный пользователь вводит в запросе UAC пароль другой, администраторской
  учётной записи, Лазейка работает от её имени: автозапуск и очистка кэша Discord
  будут относиться к той учётной записи.

## VPN

Обход и VPN работают вместе. Кнопка **«Совместимость с VPN»** (страница «Обход», включена
по умолчанию) ограничивает перехват прямыми подключениями: трафик внутри туннеля VPN
и соединение с сервером VPN обход не трогает. Подходит для любого VPN: туннель
узнаётся по драйверу адаптера (Wintun, WireGuard, TAP, OpenVPN, VPN-подключения Windows,
Radmin, ZeroTier и т. д.), а не по названию. Если подключить VPN при работающем обходе,
Лазейка сама перестроит фильтр.

Когда вы включаете обход или Telegram-прокси при работающем VPN, Лазейка спрашивает,
запускать ли их вместе, и показывает, что куда пойдёт: Discord, YouTube и Telegram — через
VPN или мимо него, через обход. Это определяется по ответу самих сайтов, поэтому работает
и для VPN с правилами внутри программы (Incy, Happ, Hiddify, v2rayN и другие).

Если весь трафик идёт через VPN, обход Discord и YouTube не нужен, но и не мешает. Чтобы
они шли через обход, а остальное — через VPN, включите в VPN раздельное туннелирование —
инструкции для популярных программ есть в «Помощи». Проверки обхода при включённом VPN
идут напрямую, мимо туннеля, — так подбор стратегий честен и при VPN.

Известные конфликты: Happ может предложить «выгрузить конфликтующие процессы» и назвать среди
них `winws.exe` — не соглашайтесь, это выключит обход. ExpressVPN с протоколом Lightway Turbo и
AdGuard VPN без WinTun работают без отдельного адаптера: их трафик Лазейка от прямого не отделит.

## Антивирусы и Microsoft Defender

Драйвер `WinDivert`, без которого не работает winws, многие антивирусы (и встроенный
Defender) помечают как `RiskTool`/`HackTool`. Это **ложное срабатывание**, а не вирус —
то же самое бывает у оригинального zapret и других DPI-утилит. Из-за него Defender может
удалять файлы Лазейки, иногда при каждом входе в Windows.

Что делает сама Лазейка:

- если файл драйвера пропал, она **переустанавливает встроенную копию пакета** и сообщает
  об этом;
- после удаления предлагает кнопку **«Добавить в исключения Defender»**. По ней в доверенные
  Defender добавляются только папки самой Лазейки целиком — `C:\ProgramData\Lazeyka` и
  `C:\Program Files\Lazeyka` (и её процессы). Это не отключение антивируса и не маскировка: всё
  остальное Defender проверяет как прежде. Обе папки создаются с доступом на запись только для
  администратора и SYSTEM, поэтому исключить их из проверки безопасно — подложить туда файл
  обычная программа не сможет.

В **переносном режиме** (папка `LazeykaData` рядом с exe) эта кнопка не работает: такая папка
лежит там, куда может писать обычный пользователь, и исключать её из антивируса небезопасно.
Если Defender мешает переносной версии — установите Лазейку обычным способом либо добавьте её
папку в исключения вручную, понимая риск.

Правильно сообщить о ложном срабатывании можно и в Microsoft — через форму
[Microsoft Defender · Submit a file](https://www.microsoft.com/en-us/wdsi/filesubmission):
тогда ложную пометку уберут у всех. Самый надёжный способ убрать срабатывание насовсем —
подписать `Lazeyka.exe` сертификатом разработчика.

Для другого антивируса (Kaspersky, ESET и т. п.) добавьте те же папки в его исключения
вручную — Defender'ом Лазейка управляет только по вашей кнопке и только для своих файлов.

## Сборка из исходников

Нужен Python 3.11 и [uv](https://github.com/astral-sh/uv).

```powershell
uv venv --python 3.11 .venv
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
.venv\Scripts\python.exe -m pytest -q          # тесты (часть ходит в сеть)
.venv\Scripts\python.exe -m app                # запуск из исходников
powershell -ExecutionPolicy Bypass -File build\build.ps1   # dist\Lazeyka.exe
```
