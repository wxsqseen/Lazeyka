# Лазейка для браузера

Расширение для Chrome, Edge, Яндекс Браузера и других браузеров на Chromium: пускает **только этот браузер** через
свой VPN Лазейки или через **любой прокси SOCKS5, SOCKS4, HTTP, HTTPS** — тогда Лазейка не нужна вовсе. Windows,
игры и другие программы ничего не замечают.

Серверы VLESS, Hysteria2 и т. п. браузер сам не открывает — для них нужна Лазейка (режим «Свой VPN Лазейки»):
расширение направляет браузер на её локальный прокси (`127.0.0.1:20808` по умолчанию). Обычный прокси (например,
купленный SOCKS5 или HTTP) расширение подключает само (режим «Свой прокси»).

## Установка

1. Скачайте `Lazeyka-browser.zip` со страницы выпуска Лазейки на GitHub и распакуйте в постоянную папку
   (удалите папку — расширение пропадёт).
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`, в Яндекс Браузере — `browser://extensions`),
   включите **«Режим разработчика»** и нажмите **«Загрузить распакованное расширение»** — выберите папку.
3. Закрепите значок Лазейки на панели браузера.

## Свой прокси — без Лазейки

1. В расширении выберите «Свой прокси — без Лазейки».
2. **Протокол** — тот, что указан у провайдера рядом с адресом (чаще всего HTTP). Расширение его не угадывает: один и
   тот же «ip:порт» у провайдера бывает HTTP, и подставить SOCKS5 значило бы сломать подключение.
3. **Адрес и порт**, **логин** и **пароль** — из личного кабинета провайдера. Можно вставить строку целиком:
   `ip:порт:логин:пароль`, `логин:пароль@ip:порт`, `http://логин:пароль@ip:порт` — поля заполнятся сами (протокол — только
   если он есть в строке).
4. Нажмите **«Включить для браузера»**. С логином браузер один раз спросит разрешение подставлять пароль — нажмите
   «Разрешить» (это право расширение просит только для прокси с паролем). Окно покажет адрес и страну выхода.

Пароль хранится в профиле браузера и в окно расширения не возвращается («сохранён»). SOCKS-прокси с паролем браузеры на
Chromium не поддерживают — для такого возьмите у провайдера HTTP-прокси или подключите его через Лазейку.

## Свой VPN Лазейки

1. «Свой VPN» → выберите сервер нужной подписки.
2. «Подключение» → режим **«Только локальный прокси»** → включите VPN.
3. В расширении нажмите **«Включить для браузера»**. Окно покажет адрес и страну выхода.

Порт меняется в «Подробнее» Лазейки — тогда тот же порт укажите в расширении. «Вход по паролю» должен быть
выключен: браузер не умеет передавать пароль прокси SOCKS5.

## Что именно делает

- Прокси только для этого браузера. По SOCKS5 и HTTP имена сайтов разрешает прокси, а не DNS провайдера
  (у SOCKS4 — сам браузер).
- WebRTC (звонки в браузере) ходит только через прокси — настоящий адрес не утекает.
- Лазейка или прокси не отвечают, а расширение включено — страницы не открываются (значок «!»): мимо них
  браузер не идёт.
- Выключили — настройки браузера возвращаются как были.

Другое расширение-прокси (например, ещё один VPN для браузера) перебивает настройки — окно об этом скажет.
